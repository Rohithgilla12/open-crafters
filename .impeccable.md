## Design Context

### Users
Mid-to-senior engineers (and ambitious mid-levels) who want to learn production infrastructure by building it. They arrive from GitHub/CLI, often in a focused evening session: pick a path, install `crafters`, grade over the wire. Secondary use: whiteboard system design, then jump to related build challenges. Hosted runner is optional for those who prefer browser submit.

### Brand Personality
**Dense · precise · industrial.** Confidence over cheerfulness. Feels like a serious infra lab / terminal craft workshop — opinionated about starting with durability, not a soft edtech playground.

### Aesthetic Direction
- **Tone:** Terminal craft — dense, precise, slightly industrial; dark theme derived from late-night coding context
- **IA:** Catalog cockpit — curated homepage with dual CTAs (Build locally / Browse journeys); full catalogs on dedicated pages
- **Visual:** Hairline rules, inset panels, fewer floating cards; mono for commands/labels only; path accents as thin signals not neon atmosphere
- **Anti-references:** Generic dark SaaS, cyan/purple glow stacks, card-soup dashboards, pill clusters, gradient text, thick side-stripe accents, Sora/DM Sans monoculture
- **Theme:** Dark only for this pass

### Design Principles
1. **First visit picks a path in seconds** — dual equal CTAs; home is curated, not a dump of 21+16 items
2. **Cards are destinations** — clickable journeys/challenges get containers; dense lists use rules/rows
3. **Accent is scarce** — mint/path colors for status and labels (~10%), not page atmosphere
4. **Terminal craft, not cosplay** — mono for install/commands; UI type is sharp and utilitarian, not “dev vibes” wallpaper
5. **Motion is feedback** — border/underline brighten on hover; no lift-shadow theater; honor `prefers-reduced-motion`
